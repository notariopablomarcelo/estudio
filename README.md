# estudio

Repo para volver a la práctica de web (HTML, CSS, JS) con un flujo guiado.

## Cómo trabajamos

- Cada ejercicio vive en su propia carpeta (`ejercicio-01`, `ejercicio-02`, ...).
- Cada carpeta tiene un `GUIA.md` con instrucciones y preguntas.
- El flujo es: `git pull` → leer/modificar en VS Code → `git add` → `git commit` → `git push`.

## Fases del aprendizaje

1. **Reconocer** — leer código funcionando y explicar qué hace cada parte.
2. **Modificar** — cambiar cosas puntuales en código existente.
3. **Completar** — rellenar huecos en un esqueleto.
4. ~~**Producir** — armar desde cero.~~ (saltada por decisión conjunta: el boilerplate no vale la pena escribir de memoria en 2026)

## Ruta de aprendizaje

Objetivo: reactivar Angular (venía de v12, apuntando a la versión moderna) con vistas a oportunidades laborales.

1. HTML básico — refresco.
2. JavaScript moderno — sintaxis y patrones (arrow functions, destructuring, spread, array methods).
3. **TypeScript** — teoría + tipar código JS existente.
4. CSS mínimo viable (flexbox, grid).
5. Angular actual (standalone components, signals, nuevo control flow).
6. Proyecto real chico + desafíos.
